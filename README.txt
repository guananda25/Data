QUESTION 2 - LIBRARY MANAGEMENT SYSTEM

Java console application with:
- Book records and CRUD
- Member records and CRUD
- Book searching
- Member searching
- Issue and return books
- Available-copy tracking
- Fine recording
- Borrowing history
- Reservations
- Reports
- Dashboard
- OOP with classes and objects
- Text-file persistence
- Input validation

FILES:
Main.java
InputHelper.java
Book.java
Member.java
Issue.java
Reservation.java
FileManager.java
BookManager.java
MemberManager.java
IssueManager.java
ReservationManager.java
Report.java

DATA:
data/books.txt
data/members.txt
data/issues.txt
data/reservations.txt

RUN:
javac *.java
java Main

All data is stored in simple text files so the project can be demonstrated without a database.
